# 企云盘 · 企业内网私有化网盘系统

> **数据 100% 留在企业自己的服务器上** —— 一套 Docker 命令部署，离线可交付。
> 三级空间 / 细粒度权限 / 断点续传 / 去重秒传 / 版本管理 / 全量审计 / 2FA。

## ✨ 核心功能

- **三级空间**：企业公共盘 / 部门盘 / 个人私有空间
- **细粒度权限**：目录级读/写/删除/分享授权（对用户/部门/全员），RBAC 三角色
- **大文件断点续传**：MinIO Multipart 分片，中断自动恢复，跨设备可续
- **去重秒传**：BLAKE3（B3SEG 多线程并行）零拷贝共享引用，不限文件大小
- **版本管理**：覆盖保留历史版本，可回滚
- **回收站**：误删可恢复，超期自动清理
- **在线预览**：图片/视频/Office/PDF；文件夹打包下载
- **内网分享**：密码/有效期/次数限制；内部人员授权；禁止外网暴露
- **全量审计**：登录/上传/下载/删除/分享全记录，合规可查
- **安全加固**：验证码、失败锁定、2FA 动态口令、密码找回、CSRF、会话管理

## 🛠 技术栈

| 层 | 技术 |
|---|---|
| 前端 | React 18 + TypeScript + Vite + Ant Design |
| 后端 | Node.js 20 + TypeScript + Express（cluster 多进程） |
| 元数据库 | PostgreSQL 16 |
| 对象存储 | MinIO（S3 兼容，单盘起步可扩分布式集群） |
| 缓存 | Redis 7（目录列表/分享 meta） |
| 部署 | Docker Compose（5 容器），支持离线交付 |

## 📦 快速部署（生产）

```bash
cp .env.example .env      # 编辑：修改所有密码/密钥为强随机值
docker compose up -d --build
# 前端 http://<IP>:8080，MinIO Console http://<IP>:9001
```
