# 09 - 定价与交付方案

> 面向销售/交付的产品化定价与交付流程。价格单位：人民币（元）。

---

## 一、产品版本划分

| 版本 | 适用客户 | 功能范围 | 建议价 |
|---|---|---|---|
| **标准版** | 中小型企业/机构 | 全部功能（三级空间/权限/断点续传/去重/版本/审计/分享/2FA） | 1.98 万 / 套 |
| **高级版** | 教育/政务/内网客户 | 标准版 + 离线交付包 + LDAP/AD 对接 + 二次开发支持（10 人时） | 3.98 万 / 套 |
| **企业版** | 大型/多分支 | 高级版 + MinIO 分布式集群部署 + 专属定制（界面/流程/对接） | 8-15 万 / 套（按需评估） |

> 说明：
> - 价格为**私有化一次性交付**（源码/镜像/文档归客户所有），非 SaaS 订阅
> - 可选**年维护费**：售价的 15%（含故障响应、版本升级）
> - 也可按**定制开发工时**报价：500-800 元/小时（或 2000 元/人日）

## 三、交付流程（标准 SOW）

```
1. 需求确认（1-2 天）
   客户环境调研（服务器配置/网络/内网 or 离线）→ 确定版本与定制项 → 报价单/合同

2. 部署实施（0.5-1 天）
   远程或上门部署 → 初始化管理员 → 基本配置（组织/部门/配额/告警）

3. 数据初始化 + 验收（1-2 天）
   导入组织架构/用户 → 按验收清单逐项测试 → 客户签字确认

4. 培训 + 交接（0.5 天）
   管理员培训（用户管理/权限/审计/备份）→ 交付包移交

5. 维护期（可选，1 年）
   故障响应（工作日 4 小时内）→ 版本升级（免费小版本）
```

## 四、定价依据（内部参考）

| 成本/价值项 | 说明 |
|---|---|
| 研发投入 | 全栈自研（前端+后端+存储+部署），20+ 功能模块，12 份文档 |
| 定制成本 | 界面 logo/名称、LDAP 对接、报表、流程定制按工时另计 |
| 竞争参照 | 同类私有网盘（如可道云 kodbox 企业版 3999/年授权、Nextcloud 企业支持） |
| 客户价值 | 数据私有 + 合规审计 + 离线可用 —— 对政企客户是刚需 |

## 五、收款方式（建议）

- 签约付 50% 定金 → 部署验收后付 40% → 维护期开始付尾款 10%
- 或：一次性付清 9 折
- 发票：个人/公司均可（如无公司主体，可挂靠/代开，或走平台担保交易）

## 六、风险与边界（务必写进合同）

- 不含：云服务器费用、域名、SSL 证书（客户自备或代购另计）
- 不含：第三方系统对接（LDAP/钉钉/企微/网盘迁移）超出约定范围按工时计
- 数据迁移服务：客户旧数据导入按 2000-5000 元/批 评估
- 交付后安全责任：系统自身漏洞 6 个月内免费修复；客户环境/操作问题不在内
