# 10 - 销售话术与演示脚本

> 面向接单/售前：找客户 → 演示 → 报价 → 成交的完整作战手册。

---

## 一、去哪里找客户（冷启动渠道）

| 渠道 | 方法 | 优先级 |
|---|---|---|
| **本地企业/机构** | 扫街式拜访：培训学校、设计公司、律所、工厂、事业单位信息科 | ⭐⭐⭐ |
| **二手平台/外包平台** | 猪八戒、程序员客栈、闲鱼（"私有网盘定制"）、淘宝（企业网盘） | ⭐⭐⭐ |
| **技术社区引流** | 掘金/CSDN/公众号发"企业私有网盘搭建教程"→ 文末留联系方式 | ⭐⭐ |
| **招投标信息** | 政府采购网搜"网盘/文档管理"小额项目，个人可参与 | ⭐ |
| **老客户转介绍** | 每交付一单，请客户介绍 1-2 个同行 | ⭐⭐⭐ |

## 二、触达话术（微信/电话首轮）

```
您好，我是做企业内网私有网盘的。

很多公司现在传文件还在用微信/百度网盘——文件不安全、离职带走资料、
容量受限、也没法给不同部门分权限。

我这套系统部署在您自己服务器上，数据 100% 不出内网：
· 部门/个人/公共盘三级空间，谁看谁能传谁不能删，权限精确到目录
· 大文件（视频、图纸）断点续传，传一半断了不用重来
· 重复文件秒传，不占双倍空间
· 所有操作有审计日志，出了问题能查是谁干的
· 还支持 2FA 动态口令登录，安全加固做全了

整套部署 1 天搞定，源码和文档都交付给您，不是租用、不是年费陷阱。

方便的话我给您搭个演示环境，您实际用 5 分钟就明白了。您看这周哪天方便？
```

## 三、演示脚本（5 分钟现场演示）

> 前提：本地已跑起演示环境（`deploy/scripts/demo.sh`，见文末）。

### 第 0-1 分钟：开场 + 登录
- 展示登录页：验证码 + 密码强度
- 演示 2FA 开启（扫 TOTP 码）
- 话术："安全是硬需求，账号体系做了全套加固"

### 第 1-2 分钟：三级空间 + 权限
- 企业公共盘 → 部门盘 → 个人空间 切换
- 建一个部门目录 → 授权"只读给某用户" → 用该账号登录演示只有只读
- 话术："权限精确到目录，防止资料外泄"

### 第 2-3 分钟：大文件上传 + 断点续传
- 拖入一个 500MB+ 文件 → 展示分片进度条
- 上传到一半刷新页面 → 自动恢复续传
- 话术："大文件不怕断网，断了自动接着传"

### 第 3-4 分钟：去重秒传 + 版本
- 同文件再传一次 → 秒传完成（零拷贝）
- 改文件再传 → 展示版本历史 → 回滚
- 话术："存储省一半，历史版本可找回"

### 第 4-5 分钟：分享 + 审计 + 收尾
- 生成内网分享链接（设密码/有效期）→ 无痕窗口访问
- 打开审计页：展示刚才所有操作的日志
- 报价："标准版 1.98 万，含源码文档部署培训，一周内交付"
- 逼单："如果这周定，我可以在维护期上再给些优惠"

## 四、常见异议应对

| 异议 | 回应 |
|---|---|
| "太贵了" | 对比：百度网盘企业版 ~500/人/年，50 人 = 2.5 万/年，我们一次性 1.98 万永久私有化 |
| "我们用钉钉/企业微信够了" | 数据在第三方云端，离职/合规/容量都是问题；私有化是硬合规需求 |
| "担心你不会维护" | 交付含运维手册 + 一年维护（故障 4 小时响应）；系统自监控告警 |
| "能试用吗" | 提供演示环境（在线 or 部署到你们测试机），满意再付款 |
| "源码不放心" | 源码完整交付可审计；支持你们 IT 团队自己二次开发 |

## 附录：演示环境一键脚本（deploy/scripts/demo.sh）

```bash
#!/usr/bin/env bash
# 演示环境一键启动：清空旧数据 → 初始化演示账号/目录/文件 → 启动
set -euo pipefail
cd "$(dirname "$0")/../../.."

echo "==> 1/4 停止并清理旧环境（保留代码）"
docker compose down || true

echo "==> 2/4 启动基础服务"
docker compose up -d postgres redis minio
sleep 8

echo "==> 3/4 构建并启动应用"
docker compose up -d --build server web
sleep 10

echo "==> 4/4 初始化演示数据（管理员 + 演示目录 + 示例文件）"
docker exec netdisk-server node dist/tools/seed-demo.js || \
  echo "(可跳过：无 seed 脚本则手动登录创建)"

echo ""
echo "✅ 演示环境就绪："
echo "   前端   http://127.0.0.1:8080"
echo "   MinIO  http://127.0.0.1:9001"
echo "   管理员  见 .env 的 ADMIN_USERNAME / ADMIN_PASSWORD"
echo "   演示流程：见 docs/10-销售话术与演示脚本.md 第三节"
```

> 补充建议（执行时再补）：
> - 可加 `server/src/tools/seed-demo.ts`：自动创建演示部门/目录/文件、若干演示账号
> - 可加截图脚本：`deploy/scripts/screenshot-demo.mjs`（用 Playwright 自动截图用于宣传页）
