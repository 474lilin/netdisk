# 05 - 离线交付指南（无互联网内网环境）

## 1. 交付物

离线交付包（`offline-package/`，由 `deploy/scripts/offline-package.sh` 或有网环境手动制作）：

```
minio-netdisk-offline-YYYYMMDD/
├── images/                  # docker 镜像 tar.gz（docker load 导入）
│   ├── server.tar.gz        # minio-netdisk/server
│   ├── web.tar.gz           # minio-netdisk/web
│   ├── postgres.tar.gz      # postgres:16-alpine
│   ├── minio.tar.gz         # minio/minio:RELEASE.2024-12-18T13-15-44Z
│   └── mc.tar.gz            # minio/mc:RELEASE.2024-11-21T17-21-54Z
├── docker-compose.yml / docker-compose.distributed.yml
├── .env.example
├── deploy/                  # nginx/postgres/minio-init/scripts
├── docs/                    # 全部文档
├── source/                  # 前后端源码（不含 node_modules）
└── README-离线安装.md
```

## 2. 制作离线包（有网环境，一次性）

```bash
# Linux
./deploy/scripts/offline-package.sh /data/offline

# Windows PowerShell
powershell -ExecutionPolicy Bypass -File deploy\scripts\offline-package.ps1 D:\offline
```
> 注意：Windows 导出 gzip 需要环境有 gzip（或改用 7-Zip 压缩 tar 文件）。

## 3. 内网安装

```bash
# 1. 安装 Docker（离线 rpm/deb 包或离线安装脚本）
#    CentOS: yum install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin（离线包）

# 2. 导入镜像
cd images
for f in *.tar.gz; do docker load < "$f"; done
docker images | grep -E 'minio-netdisk|postgres|minio'

# 3. 初始化环境
cp .env.example .env
vi .env   # 修改全部密码/密钥；MINIO_PUBLIC_ENDPOINT 填本机内网 IP

# 4. 启动
docker compose up -d

# 5. 验证 + 登录
curl http://127.0.0.1:8080/api/health
```

## 4. 内网开发/二次开发（可选）

离线包内含源码（source/）。内网开发机需要 Node.js 18+ 与 npm 私服/离线缓存：

```bash
# 方案 A：npm 离线缓存（制作离线包时在有网机器执行）
npm pack  # 或 npm cache 预热
# 方案 B：内网 npm 私服（Verdaccio/Nexus）同步所需依赖
# 方案 C：直接拷贝有网开发机已装好的 node_modules（版本一致即可）
```

## 5. 无外网环境的运行时依赖清单

| 组件 | 是否需外网 | 说明 |
|---|---|---|
| 前端静态资源（React/AntD/pdf.js/docx-preview/xlsx） | 否 | 全部打进 web 镜像 |
| 后端依赖（express/pg/minio/bcryptjs 等） | 否 | 全部打进 server 镜像（纯 JS，无原生编译） |
| 文档预览 | 否 | PDF/图片/音视频/docx/xlsx 本地渲染；旧版 .doc/ppt 提示下载 |
| 系统时钟同步 | 建议内网 NTP | JWT/MinIO 签名依赖时间一致 |
